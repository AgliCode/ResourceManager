How to get your Gemini API key

Follow these steps to create your own Gemini API key and connect it to ResourceManager.

1

Search for Google AI Studio

Open Google and search for Google AI Studio. Open the official website.

2

Open the Dashboard

Once you are on the Google AI Studio website, click Dashboard to access the available tools.

3

Find the API Keys section

Locate and click Create API key to open the API key management page.

4

Create a new API key

Click the option to create a new API key. Enter a name for your key and select a project. Feel free to use the default Gemini project. If you prefer, you can also create a new one. Confirm your selection.

5

Copy your API key

Your new API key will appear on the screen. Click the copy icon to copy it, then return to ResourceManager and paste it into the API key field.

Keep your API key safe!

Your API key is private. Do not share it with anyone or publish it in public repositories. ResourceManager can securely store your key locally on your computer if you enable the Remember me option.
