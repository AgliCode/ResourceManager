# ResourceManager

**ResourceManager** to aplikacja desktopowa stworzona w technologii WPF, której celem jest ułatwienie zarządzania plikami zasobów `.resx` w projektach .NET.

Aplikacja pomaga w uzupełnianiu brakujących tłumaczeń, edycji wpisów oraz organizacji zasobów językowych.

## Funkcjonalności

- Odczytywanie plików `.resx` z wybranego projektu.
- Wyszukiwanie brakujących tłumaczeń.
- Przeglądanie i edycja wpisów zasobów.
- Uzupełnianie tłumaczeń na podstawie istniejących kluczy.
- Podgląd postępu uzupełniania tłumaczeń.
- Wykorzystanie sztucznej inteligencji do wspomagania procesu tłumaczenia zasobów. AI może generować propozycje tłumaczeń, które użytkownik może następnie sprawdzić i zaakceptować przed zapisaniem zmian.

## Technologie

- C#
- .NET 8
- WPF (Windows Presentation Foundation)
- XML / RESX
